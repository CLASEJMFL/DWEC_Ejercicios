Ejercicio 3: La Lista Dinámica (Crear y Borrar nodos)

Objetivo: Manejar createElement, appendChild y remove.
1. Al hacer clic en "Agregar Elemento":
    - Crea un nuevo elemento li.
    - Pídele al usuario el texto mediante un prompt().
    - Añade el li a la lista ul.
2. Al hacer clic en "Borrar Último":
    - Selecciona el último hijo de la lista (lastElementChild).
    - Elimínalo del DOM. Comprueba primero si existe para que no dé error.
